### SCAN QR

2. Pair your WhatsApp locally (no third-party QR/session site)

   ```bash
   npm install
   node pair.js        # enter your number, then type the code shown on your phone
   npm start
   ```

   - The session is stored only in `./lib/session` (permissions 0700/0600) and is never uploaded.
   - Set `SUDO=<your number>` in `config.env` so only you can run owner commands.
   - Set `WORK_TYPE=private` to stop other people from using public commands.
   - Check WhatsApp > Settings > Linked devices regularly and remove anything you don't recognise.
